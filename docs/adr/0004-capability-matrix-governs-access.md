# One capability matrix governs navigation, pages and commands

Access to a staff-facing area is declared once, in `packages/backend/convex/utils/capabilities.ts`, as a Capability with its Module, Entitlement, Permissions and canonical route. The sidebar, command palette and page guards read the caller's states from `capabilities.forOrganization`, and backend gates throw `ConvexError({ code: "CAPABILITY_UNAVAILABLE", reason })` instead of plain errors, so what staff see matches what commands allow and every refusal can be explained.

The first missing dimension is the reason: Module, then Permission, then Entitlement, so staff whose Role lacks access are never told to upgrade. Coded failures go only to members: shared gates give non-members the legacy uncoded error, which clients see redacted, and `requireCapability` checks membership before anything else and refuses non-members uncoded too, so outsiders learn nothing about an Organization's Modules or plan. A Permission belongs to at most one Capability (its `owns` list in the matrix, such as every `loans.*` Permission to Loans), and `requirePermission` sends an owned Permission through `requireCapability`, so its Module and plan come from the matrix in this order wherever it is checked. Modules are free catalog choices and Entitlements are the paid plan (Option A in `docs/decisions/monetization-coherence.md`); where an existing gate disagreed with backend enforcement, the matrix follows the backend and pricing is unchanged. A Module added after the records it covers, such as Insurance, only lists its area in navigation (`listedWithModule`) so existing records stay reachable. Navigation hides destinations whose Module is off, that are unlisted, or whose Role lacks access, and shows plan-gated destinations locked so their page can explain the plan.

A section of a page that needs a Permission beyond its Capability's, such as location utilization and scheduled reports on Analytics (`utils/analyticsSections.ts`), uses `CapabilityGuard`'s `permission`. The page skips that section's queries and shows its reason in place, so one missing Permission never takes down the page.
