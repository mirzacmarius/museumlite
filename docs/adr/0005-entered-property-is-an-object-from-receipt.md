# Entered property is an Object from receipt, outside the collection until accessioned

Receiving property under an Entry creates its Object at receipt, catalogued under the entry number and placed through a guarded `entry_receipt` movement. Custody, condition, movement, media and register evidence therefore attach to one Object identity from the first day, and accessioning reuses that Object instead of publishing a new one: approval gives it the permanent identifier and keeps the entry number as an alternate with a closed history interval. This is assigning a permanent number to newly accepted material, not renumbering to fix data (ADR 0002 still applies).

While its Entry is not accessioned the Object is not part of the collection: it cannot be deaccessioned, lent or transferred to another institution, and inventory metrics count it as incoming rather than owned. Unaccessioned property leaves through a recorded exit to a named recipient, which archives the Object and records a custody departure; it never creates a Deaccession. Incoming loans keep their own return-to-lender exit. We accepted that catalog lists include entered Objects (each Object's page states its Entry) in exchange for not adding a collection status that every reader would have to handle.
