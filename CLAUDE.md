# Project instructions

Read `AGENTS.md` for shared project rules before working in this repository. For backend work, also read `packages/backend/convex/AGENTS.md` and `convex/_generated/ai/guidelines.md`.

## Agent skills

### Issue tracker

Issues and PRDs live in Linear under the MuseumLite workspace, MUS team. See `docs/agents/issue-tracker.md`.

### Triage labels

Matt's five triage roles map to the MUS workflow statuses and optional labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use a single-context layout with a root `GLOSSARY.md` and `docs/adr/` for architectural decisions. See `docs/agents/domain.md`.
